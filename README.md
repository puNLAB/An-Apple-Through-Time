# The Passage of an Apple

An interactive art project exploring life and the passage of time through an apple's gradual decay.

Inspired by the Shanghai Sign Language gesture for **“life,”** the project allows users to interact with the screen through hand gestures and witness an apple's transformation from fresh to rotten.

## Features

- **Hand Gesture Recognition** — Real-time hand tracking using MediaPipe.
- **Interactive Experience** — Use the Shanghai Sign Language gesture for “life” to interact with the screen.
- **Visual Transformation** — Explore the gradual decay of an apple through a photographic sequence.
- **Image Processing** — Use OpenCV to process and display images.

## Tech Stack

- Python
- OpenCV
- MediaPipe

## Artistic Concept

By connecting a familiar everyday object with gesture-based interaction, this project explores how time, life, and decay can be experienced through digital imagery. It reflects on the relationship between the physical and virtual worlds, inviting viewers to reconsider the meaning of ordinary objects and the passage of time.
